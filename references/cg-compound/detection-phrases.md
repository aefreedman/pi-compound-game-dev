# Solution Confirmation Candidates

Use these phrases to discover possible solved problems; a phrase alone is not proof:

- that worked / it worked
- it's fixed / that fixed it / fixed it
- working now / works now
- problem solved / issue resolved
- that did it / perfect / success
- that's better / much better
- resolved / done / completed
- similar success or completion phrases

For each candidate, inspect the surrounding context and record at least one provenance source directly supporting the reported outcome:

- explicit user confirmation tied to the original symptom or acceptance target;
- direct validation of the reported scenario;
- a reproduced failure followed by a passing equivalent check; or
- another recorded evidence source that directly supports resolution.

Generic completion language such as "done" or "completed," an implementation-complete statement, or an unrelated passing check does not establish a solved problem. If no qualifying provenance is present, skip solution-document creation. If evidence proves only a subcomponent, keep that narrower claim and record the remaining player-path or acceptance gap rather than calling the broader outcome fixed.
